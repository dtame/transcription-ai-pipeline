# Back-cover layout strategy

No PDF is produced. No biography is written.

Current project:

- author biography: MISSING_OPTIONAL
- book description: NOT_STARTED
- arrangement now: color_field_only
- background color: PENDING_FRONT_COVER
- invented biography: False

The back face is independent of the front image. Its background is a flat color chosen only after the front cover is accepted.

Reflow:

- MISSING biography removes its band and returns that space to the color field.
- A present description then occupies the text column alone.
- When both texts exist, the description stays above the biography with a gap.
- Neither text is invented or approved in this phase.

ISBN, barcode, and publisher stay `NOT_APPROVED` until a person approves a public fact. Testimonials, awards, and invented quotations stay out of the layout.
